# Schema — the rules of this fact register

One note type. Every note is a verifiable claim about a shipped DSH package, not an opinion.

## Note type

| `type:` | Lives at | Carries |
|---|---|---|
| fact | `facts/<slug>.md` | one claim: verbatim quote(s), the package and version, the source path, its SHA-256, and the spec clause it feeds |

## Required frontmatter

| Field | Meaning |
|---|---|
| `type` | `fact` |
| `title` | the claim in a few words |
| `description` | one sentence for the generated index |
| `status` | `verified` or `stale` |
| `package` | exact npm package name, e.g. `@deepseek-ai/dsh-skill-filesystem` |
| `version` | exact package version the quote was taken from |
| `source` | file path relative to the package root, e.g. `README.md` |
| `sha256` | lowercase hex SHA-256 of that file at that version |
| `spec` | the contract clause this fact feeds (e.g. `docs/spec.md §8; Appendix A`) |

## Body

- `## Quote` — one or more `> ` blockquote lines, **verbatim** from the source. The checker requires each line to appear in the source file.
- `## Feeds` — which code/contract clause consumes it; never restate the contract.
- `## Drift` — how to re-check and what to do when it fails.

## Rules

- Never tidy a quote "for readability": trim only at sentence or line boundaries, and keep the exact characters.
- A source that ships only code (for example `lib/types/builtin.js`) is quoted by exact source lines, not by a README summary.
- `_index.md` is generated by `_tools/index.py`; never hand-edit it.
