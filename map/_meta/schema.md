# Schema — the rules of this map

The closed set of card types, the labels they carry, and how a citation is written. When practice and this file disagree, reconcile the same day: schema drift is how maps rot.

Node types: `object`, `process`. Add a third only when someone will query it.

## Card types

| `type:` | Lives at | Carries |
|---|---|---|
| object | `objects/<noun>.md` | one load-bearing noun: its why, shape, connections, blast radius, surfaces |
| process | `processes/<verb>.md` | one movement that actually runs. **None yet** — the four stages live in `docs/spec.md` §5, not in code. |

## Labels that make it queryable

| Field | Values | Meaning |
|---|---|---|
| `universe` | `live` \| `leftover` \| `ghost` | in force · no longer the path · named but not wired |
| `status` | `verified` \| `stale` \| `stub` | card freshness |
| `implementation` | `ghost` \| `partial` \| `live` | code reality: no file · some files · code exists |
| `verified` | `YYYY-MM-DD @ <commit>` | required whenever `status: verified` |
| `entity` | text | the owning contract or source; `path:line` once code exists |
| `cluster` | text | how an editor asks; this map uses one: `contract` |

`universe` describes the *thing*; `implementation` describes the *files*. They are deliberately separate: a contract can be `live` and binding while its file is still a ghost. This is the field that tells a cold agent what exists — the repo previously said it only in prose.

## Universes

| Universe | Meaning | Do |
|---|---|---|
| live | in force | implement and cite against these |
| leftover | still present, no longer the main path | touch only if that path is in scope |
| ghost | named or filed, not wired (stubs, planned files) | **do not implement against a ghost as if it existed**; a ghost path is named in backticks, never linked |

## Citations

- Code: `path:line`. If a comment and the code disagree, the code wins and the card says so.
- Contract: `docs/spec.md` §N. This map never copies contract tables; it points.
- Ghost: name the planned path in backticks and mark it **ghost**; do not link it, so link checking stays honest.
- Always end a card with at least one `See` link that resolves today.

## Naming

- The card file is the noun, kebab-case (`lockfile-write-matrix.md`).
- One noun per card; a noun that needs two cards is two nouns.
- `_index.md` is generated by `_tools/index.py` from card frontmatter — never hand-edited.
